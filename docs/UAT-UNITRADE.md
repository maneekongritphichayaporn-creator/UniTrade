# UniTrade — ผลการทดสอบการยอมรับระบบ (UAT)

## สรุปผล UAT

| รายการ | ผล |
|---|---|
| โครงการ | UniTrade |
| ขอบเขต | User Stories US-01–US-06 และเกณฑ์การยอมรับ |
| ผลรวม | **ผ่าน 6 จาก 6 User Stories** |
| แหล่งที่มาของผล | ทดสอบเมื่อวันที่ 13 พฤศจิกายน 2026 |

| UAT ID | User Story / หัวข้อที่ยอมรับ | ผลลัพธ์ที่คาดหวัง | ผล |
|---|---|---|---|
| UAT-01 | US-01 — สมัครและเข้าสู่ระบบ | ผู้ใช้ CU ดำเนินการสมัคร/เข้าสู่ระบบและเข้าถึงฟังก์ชันสำหรับสมาชิกได้ | **ผ่าน** |
| UAT-02 | US-02 — สร้างประกาศขาย | ผู้ขายกรอกรายละเอียด เพิ่มรูปภาพที่รองรับ และสร้างประกาศด้วยสถานะเริ่มต้นที่กำหนดได้ | **ผ่าน** |
| UAT-03 | US-03 — จัดการประกาศของตนเอง | ผู้ขายจัดการประกาศและสถานะของตนได้ โดยจำกัดสิทธิ์ตามเจ้าของและมีขั้นตอนยืนยันก่อนลบ | **ผ่าน** |
| UAT-04 | US-04 — ค้นหาและกรองสินค้า | ผู้ซื้อค้นหา ใช้ตัวกรองร่วมกัน เรียงผลลัพธ์ และเห็นข้อความเมื่อไม่พบสินค้าได้ | **ผ่าน** |
| UAT-05 | US-05 — Wishlist และการติดต่อผู้ขาย | ผู้ใช้ที่เข้าสู่ระบบจัดการรายการที่บันทึกไว้และดำเนินการตามขั้นตอนติดต่อผู้ขายที่กำหนดในการทดสอบได้ | **ผ่าน** |
| UAT-06 | US-06 — รายงานและจัดการประกาศ | ผู้ใช้ส่งรายงาน และผู้ดูแลระบบที่ได้รับอนุญาตตรวจสอบ/ดำเนินการกับรายงานได้ | **ผ่าน** |
